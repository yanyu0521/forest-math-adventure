# 森林數學大冒險

Phaser.js browser game for elementary math practice.

## Start

```bash
npm install
npm run dev
```

## Play

- Move with the arrow keys or WASD; on a phone, hold the direction buttons.
- Collect the correct wooden answer sign for 10 points.
- A wrong sign costs 5 points and disappears, leaving the other choices available.
- Complete three questions in each of the five levels: addition, subtraction, multiplication, division, and mixed review.
